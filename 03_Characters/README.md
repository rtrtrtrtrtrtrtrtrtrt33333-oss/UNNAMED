# Character catalogue

Each character has one folder here, regardless of their universe. Their original
universe is stored in `assets/data/character-data.css` as `--character-universe`.

Universe pages remain responsible for regions, lore, timelines, and navigation.
The character pages use that universe's header and links through
`assets/data/character-catalog.css`.

When adding a character, copy an existing character folder, then set
`--character-universe` to the desired world.
