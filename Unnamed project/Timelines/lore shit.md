# Project instructions

This repository contains a website and game/worldbuilding project.

## Lore

Canonical lore is stored in:

docs/lore/

Before writing or modifying lore-related content:
1. Read docs/lore/INDEX.md.
2. Read TIMELINE.md when chronology matters.
3. Read relevant faction, character, and aspect files.
4. Treat those files as canonical unless the user explicitly changes canon.

When the user establishes new canon, update the relevant lore document.

Do not invent missing lore merely to fill gaps.
Mark unresolved information as unresolved.

## Writing style

Lore text should use simple, readable language.

Avoid overly academic or bureaucratic wording.
Prefer:
"Со временем металла стало не хватать."

Instead of:
"Продолжительное истощение стратегических материалов..."

Keep lore concise unless more detail is requested.

## World terminology

"Artificial" refers to conscious artificial beings.
"Robot" refers to non-conscious machines and automation.

Do not use these terms interchangeably.

## Website

Preserve the existing structure and visual language of pages.

Reuse existing templates where possible.
Do not add global CSS for one-off page elements when an inline style is sufficient.
